# Codex Foundry — Product Vision

## One-line pitch

Codex Foundry transforms every engineering task into verified code changes, executable proof, and reusable engineering memory so every future Codex task becomes smarter, safer, and more efficient.

## The future we are demonstrating

AI engineering should compound. A successful agent run must not disappear into a chat transcript or a one-off pull request. Foundry captures the requirement, architectural decisions, proof of behavior, and regression evaluation as durable, human-readable project memory.

The outcome is not "an agent that writes code." It is an engineering system that turns each verified task into context and safeguards for the next task.

## Product promise

For one high-risk engineering task, a developer can see:

1. why Foundry selected its context;
2. what behavior it must prove;
3. Codex make and verify a change in an isolated worktree; and
4. the resulting knowledge become reusable engineering memory.

## North-star outcome

For the Build Week MVP, Foundry resolves a duplicate-charge checkout retry bug and leaves behind enough evidence that a later bad change is automatically rejected.
