# G3E — Reviewable PAY-17 Patch Artifact

## Scope

Render a human-reviewable patch bundle for the independently verified PAY-17
candidate.

## Acceptance criteria

- Shows state, scope, exact diff, fixed proof contract, baseline failure, and
  independently verified candidate results.
- Links verifier evidence and states limitations.
- Requires an explicit human approve/reject decision.
- Does not merge, commit the candidate, deploy, or write the vault.
